# SYP Converter

USD → new & old Syrian pound (central bank + street rate) and Egyptian pound. Mobile-first, installable on iPhone.

- Official + EGP: open.er-api.com (live)
- Street: sp-today.com (live, with a backup in `rates.json` refreshed every 30 min by GitHub Actions)
- Old SYP = New SYP × 100
